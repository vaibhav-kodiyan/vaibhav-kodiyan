How I work

Start at the assumption

Most agent failures are specification failures. I write the assumption down first, then build the smallest thing that can falsify it.

Make the work replayable

Every step an agent takes is recorded with the context that produced it, so a reviewer reads intent instead of reconstructing it from a diff.

Experience

Agentic Engineer, Qaynel Agentic Solutions

Current

Building Rig: a runtime for coding agents with sandboxed execution, repo-aware context, and review loops that catch what the model missed. Nothing an agent runs reaches production until a human has seen the trace it produced.

Coding agents fail quietly — they pass tests, open a pull request, and leave a reviewer to reconstruct intent from a diff. Rig's self-review pass is built to catch exactly that: it has flagged issues like a retry loop that silently swallowed a failure, with tests still green, before the change ever reached a human reviewer.

Evidence-driven: a layer that can't show what it caught last week gets removed.
